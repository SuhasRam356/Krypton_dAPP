# Agentic AI Features (OpenMAIC Reference)

When building new projects involving Agentic AI, consider incorporating these core features inspired by OpenMAIC:

1.  **Agent Workbench**: A chat-first workspace that plans, builds, and revises content iteratively (like a curriculum or a project). It should support durable sessions so tasks survive restarts, allowing users to cancel, resume, and steer anytime.
2.  **Multi-agent Collaboration**: Create specialized agents (e.g., an AI Teacher and AI Classmates) that can interact with the user and each other in real-time, share context, and perform specific roles (lecturing, discussing, reviewing).
3.  **Seamless Integration (OpenClaw style)**: Build integrations that allow the AI system to be triggered directly from messaging apps (Slack, Telegram, Feishu) without requiring local setup from the end-user.
